### Use Case: Warehouse Robot Pathfinding

### Problem Statement

Autonomous mobile robots (AMRs) are increasingly used in warehouses to transport materials, move inventory, and complete tasks. These robots must navigate through warehouse environments while avoiding obstacles and finding efficient routes to their destinations.

One challenge is determining the most efficient path when multiple routes are available. Longer routes require more travel time and energy, which can reduce the robot's operating efficiency.

Our project explores how quantum optimization could assist with selecting efficient paths for warehouse robots. By generating multiple possible routes and evaluating their energy costs, the system attempts to select the route with the lowest travel cost while satisfying the requirement that only one route is selected.

### Why Quantum Computing?

The route-selection problem can be represented as a combinatorial optimization problem. Each candidate route is represented by a binary variable, where a value of 1 indicates that the route is selected and 0 indicates that it is not.

Our project uses the Quantum Approximate Optimization Algorithm (QAOA) to explore this problem. QAOA is designed for combinatorial optimization and uses a parameterized quantum circuit to explore possible solutions.

The objective is to minimize the energy cost of the selected route while requiring that exactly one candidate route be selected. In the simulator, this constraint is included in the optimization problem. In the current hardware implementation, it is checked through classical filtering after measurement. We investigate whether quantum hardware can be used to solve this type of route-selection problem and compare its results with a classical approach.

### System Overview

The system simulates an autonomous warehouse robot navigating through a grid-based warehouse environment. The grid contains open spaces, obstacles, and charging stations.

The robot begins at a starting position and must reach a designated destination. The classical A* pathfinding algorithm generates an initial route while avoiding obstacles. Additional candidate routes are generated by temporarily blocking cells along the original route and running A* again.

Each candidate route is assigned an energy cost based on the distance traveled and the number of direction changes. Straight movements have a cost of 1.0, diagonal movements have a cost of approximately 1.414, and direction changes add a penalty of 0.5.

The candidate routes are then passed to the quantum optimization algorithm. QAOA evaluates the route-selection problem and attempts to identify the candidate with the lowest energy cost. The simulator includes the one-route constraint during optimization, while the current hardware implementation filters measurement results afterward to keep only outcomes that select exactly one route.

### Project Goals and Expected Outcomes

The main goal of this project is to investigate how quantum optimization can assist warehouse robots in selecting efficient travel routes.

The project aims to:

Generate multiple possible paths between a robot's starting point and destination.

Calculate the travel energy cost of each candidate route.

Use QAOA to select a route while satisfying the one-route selection constraint.

Compare quantum optimization results with classical A* pathfinding.

Explore how this approach could apply to real-world warehouse automation.

The expected outcome is a working simulation that demonstrates how quantum optimization can be applied to a practical robot-pathfinding problem. The project also evaluates the limitations of current quantum hardware and whether the approach offers practical benefits over classical methods.

### Experimental Setup

The project was tested using both a local quantum simulator and IBM Quantum hardware.

The local simulator used Qiskit's StatevectorSampler with QAOA and the COBYLA optimizer. The optimizer used up to 30 iterations to find parameters for the quantum circuit.

For hardware testing, the project used IBM Quantum's ibm_marrakesh processor through the Qiskit Runtime Sampler. Each hardware job used 1,024 measurement shots. The hardware implementation used a QAOA circuit with one repetition and fixed circuit parameters of 0.5.

Two separate hardware tests were performed. Each test used three newly generated warehouse layouts, allowing the system to evaluate different pathfinding scenarios.

For each scenario, the number of binary variables depended on the number of candidate routes successfully generated. The hardware measurements were filtered to identify valid solutions that selected exactly one route. Among the valid measured solutions, the system selected the route with the lowest calculated energy cost.

### Real-World Applications

This project is based on warehouse environments where autonomous mobile robots are used to transport inventory and materials between different locations.

Efficient pathfinding can help reduce unnecessary travel distance, which can lower energy consumption and improve overall operating efficiency. In warehouses with multiple robots, route optimization could also contribute to better coordination and reduced congestion.

The approach explored in this project could potentially be expanded to larger warehouse environments with more robots, destinations, obstacles, and charging stations. Future development could investigate how quantum optimization might assist with more complex routing and scheduling decisions.

Although this project uses a simplified warehouse simulation, it provides an opportunity to explore how quantum computing could be applied to practical industrial optimization problems.
